# Databricks ETL with SQL: Language-Learning App Pipeline

A hands-on project for practising incremental SQL ETL pipelines on Databricks, built around data from a fictional language-learning app.

It uses the medallion architecture (bronze → silver → gold) with **Streaming Tables** for ingestion and **Materialized Views** for transformations, and runs on Databricks Free Edition with a serverless SQL warehouse.

> Work in progress: built step by step as a learning exercise.
